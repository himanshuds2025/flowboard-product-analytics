# Flowboard Product Analytics
## Business Decision Memo

**Subject:** Activation, retention and product usage findings  
**Purpose:** Identify the main product problems and recommend actions supported by the analysis.

### Executive summary

The analysis indicates that Flowboard has an activation problem, a significant drop between project creation and task creation, and a decline in weekly active usage.

The collaboration prompt experiment showed a statistically significant improvement in invite acceptance. The onboarding experiment showed no significant improvement.

### Key findings

1. **Activation:** Only 36.33% of users completed a task within seven days of signup.
2. **Acquisition:** Referral users had the highest D7 activation rate at 43.70%. Paid search had the lowest at 27.92%.
3. **Funnel:** The largest user drop off occurred between project creation and task creation.
4. **Retention:** D30 retention was 2.43% among activated users and 1.76% among users who did not activate.
5. **Product usage:** Weekly task completing users declined 32.2% from the July peak of 2,922 to 1,980.
6. **Experiments:** The new onboarding flow showed no significant improvement. The collaboration prompt increased invite acceptance by 1.79 percentage points, a statistically significant result.

### Recommendations

**1. Improve the project to task journey**

Investigate why users create projects but do not proceed to creating tasks. Prioritise reducing friction in this part of the product journey.

**2. Investigate paid search users**

Examine whether the expectations created by paid search campaigns match the actual product experience. Their activation rate is the lowest across acquisition channels.

**3. Continue testing the collaboration prompt**

The invite acceptance result is promising. Run a follow up experiment to validate the improvement and examine whether it translates into stronger engagement and retention.

**4. Investigate the decline in weekly active usage**

Examine existing user activity and identify when and where usage began declining. The available data shows the decline but does not establish its cause.

**5. Rework the onboarding experiment**

The current onboarding change did not produce a significant improvement. Further changes should be tested against clearly defined activation outcomes.

### Limitations

- The dataset is synthetic and does not represent actual Flowboard customers.
- Observed relationships do not establish causation.
- Experiment assignment does not independently verify actual exposure or randomisation.
- The available product change history is limited, so it cannot explain the decline in usage.
- The latest period has incomplete signup observation, which limits conclusions about recent new user activity.

### Conclusion

The analysis identifies early activation and the project to task journey as the main areas requiring attention. The collaboration prompt is the only tested intervention that produced a statistically significant positive result.

The recommended next step is to investigate the project to task drop off, continue testing the collaboration prompt, and examine the decline in existing user activity.
